# VisionTrack AI – Object Detection & Tracking

**CodeAlpha Internship – Task 4**

VisionTrack AI is a computer vision application that detects objects in images and videos and tracks objects across video frames.

### Features
- Image object detection
- Video object detection and tracking
- Object counting and classification
- Adjustable confidence threshold
- Processed video download

### Technologies Used
- Python
- Streamlit
- YOLO (Ultralytics)
- OpenCV
- ByteTrack

### Installation & Usage

```bash
git clone https://github.com/shzz09/CodeAlpha_ObjectDetection_Tracking.git
cd CodeAlpha_ObjectDetection_Tracking
pip install streamlit opencv-python ultralytics
streamlit run app.py
```

### Model
YOLO11n (`yolo11n.pt`)
